# Narwhal-Trader
Customizable trader for automating asset management

Should be able to:
  - Run on a cloud with access to the trading market, global information scraping, and engage with foreign markets 24/7
  - Client-side account access to the Narwhal trading platform
  - Trade stocks
  - Trade bonds, gold, and other secure assets
  - Automatically engage in portfolio diversification
  - Automated strategic asset allocation based on market future and external events
  - Alorithmic trading using a proprietary algorithm -> (in the future) users able to develop and deploy their own algorithm
  - Paper trading & Historical market data replay feature

Trading algorithm:
  - Automated feature (per individual capital, global macroeconomic situation):
    - Position size control
    - Stop-loss / trailing stop-loss
    - Maximum daily loss limits
    - Portfolio volatility targeting
    - Drawdown protection
    - Margin monitoring
    - Exposure limits by sector/asset
  - Strategic asset allocation:
    - Economic indicators
    - Earnings reports
    - Macroeconomic signals
    - Real-time world news
  - Trading feature:
    - Real-time price feeds
    - sentiment analysis
  - Strategy & Algorithm Library:
    - Users publish strategy
    - Algorithm publishing
    - Version stretegy
    - Equational algorithm & machine learning algorithm
